# Davis restaurant map

STA 141B bonus assignment showing three Davis restaurants on an 800 × 600 Folium map centered on Philz Coffee.

[Open the live Davis restaurant map](https://kavishkartha05.github.io/davis-map/).

From the repository root, regenerate `map.html` with:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python build_map.py
```
